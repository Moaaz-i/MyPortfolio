## Who I Am

I'm **Moaaz Yahia Zakaria** — a Full-Stack & Systems Engineer who builds across the entire software stack. I create **developer tools**, **HTTP frameworks**, **encrypted databases**, **programming language compilers**, and **embedded C++ systems**.

Everything I build follows a simple principle: **zero dependencies, maximum performance, no compromises.**

## What Drives Me

I'm fascinated by the fundamentals — how a single clock cycle on an AVR chip, how a radix trie routes HTTP requests in C++, how AES-256-GCM encrypts a document before it leaves the process. I build tools that other developers actually want to use: fast, minimal, well-documented, and portable.

## The Work

Across my projects I've:

- Built **Velociradix** — a Node.js HTTP framework powered by a C++17 native engine with kqueue/epoll workers and a custom HTTP parser
- Created **FLASH** — a zero-knowledge encrypted document database engine with HNSW vector search, AI-native RAG, and ORE range tokens
- Developed **JPROT** — a portfolio site generator that serves Markdown directly with zero build steps, SSR, and SPA navigation
- Written **CronFlex** — a zero-dependency task queue, cron scheduler, and rate limiter with a live monitoring dashboard
- Shipped **AeroCI** — a local digital twin for GitHub Actions that simulates CI pipelines in milliseconds without burning remote quota
- Built **VelociForge** — a virtualized package engine with 0.70ms ephemeral startup and SBOM generation
- Created **Codinam** — a custom programming language with a C++ compiler, standard library, and VS Code extension
- Engineered **MicroTaskX** — a high-performance micro-RTOS for Arduino with CPU profiling, power management, and compile-time task configuration
- Developed **FlareDom** — a C++ UI framework that builds responsive web dashboards on ESP8266/ESP32 without HTML files or SPIFFS
- Built **Ultra1602Ultimate** — a flicker-free LCD 1602 library with async text slots, progress bars, and direct port manipulation
