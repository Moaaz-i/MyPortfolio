## What My Portfolio (Next.js) Is

**My Portfolio** is a modern, fully responsive personal portfolio website built with Next.js, TypeScript, and Tailwind CSS. It showcases projects, technical skills, and professional experience with a clean, polished UI and smooth animations.

## Core Features

### Project Showcase

Featured projects presented with live demos, screenshots, tech stack tags, and direct links to source code — built dynamically from project data.

### Skills & Experience

Categorized skill sections with proficiency indicators and detailed experience descriptions.

### Responsive Design

Optimized for desktop, tablet, and mobile with fluid layouts and breakpoint-aware components.

### SEO Optimized

Server-side rendered pages with proper meta tags, Open Graph images, and semantic HTML structure.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Design:** Modern portfolio with animations and transitions
