## What Needful Is

**Needful** is a modern, full-featured e-commerce platform built with Next.js 16 (App Router), TypeScript, and Tailwind CSS. It provides a complete shopping experience with product browsing, advanced filtering, cart management, user authentication, and address management.

## Core Features

### Product Catalog & Search

Browse products with detailed information, images, and pricing. Real-time product search with autocomplete, category and brand filtering.

### Shopping Cart

Add, remove, and update cart items with real-time quantity management and persistent state across sessions.

### User Authentication & Accounts

Secure login/signup system with protected routes, profile management, and order history.

### Address Management

Add, edit, and delete multiple shipping addresses tied to a user profile.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript (full type safety)
- **Styling:** Tailwind CSS
- **State:** Zustand
- **Notifications:** React Hot Toast
- **Image Carousel:** Swiper.js
- **API:** Axios with RESTful endpoints
