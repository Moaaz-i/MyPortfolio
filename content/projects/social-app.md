## What Social App Is

**Social App** is a modern, professional networking platform similar to LinkedIn — built with React, Tailwind CSS, and a FastAPI backend. A complete full-stack application with authentication, real-time features, and a polished UI.

## Core Features

### Authentication & Security

Complete login/signup system with JWT tokens, secure bcrypt password hashing, 7-day token expiry, and protected API routes throughout the application.

### Profile Management

Comprehensive user profiles with headline, bio, location, skills with endorsement system, work experience tracking, education history, certifications, and profile/cover pictures.

### Professional Networking

Connect with other professionals, follow profiles, and build your network — the core interaction model of a professional social platform.

### Responsive Design

Fully responsive interface optimized for desktop, tablet, and mobile — built with Tailwind CSS utility classes for consistent styling across breakpoints.

## Tech Stack

- **Frontend:** React, Tailwind CSS, modern component architecture
- **Backend:** Python FastAPI with REST API design
- **Auth:** JWT tokens with bcrypt hashing
- **Database:** Persistent storage with proper data modeling
- **Deployment:** Vercel (frontend) with API backend
- **Design:** Professional networking UI/UX
